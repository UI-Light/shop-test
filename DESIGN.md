# DESIGN.md
Style: clean, minimal, lots of whitespace. Light theme only.
Colors: background white, text slate-900, accent one color (indigo-600), borders slate-200.
Font: system font stack. Layout: centered max-w-5xl, responsive grid (1 col mobile, 3-4 desktop).
Components: simple cards, one primary button style, clear empty states and error messages.
No animations, no icon libraries unless needed.
